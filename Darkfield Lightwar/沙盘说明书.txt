操作按键：
Esc 依次关闭统计/创造/观察面板；都不开时显示/隐藏基本UI
M / H 显示/隐藏统计面板（统计排行）
N 显示/隐藏创造面板
K 显示/隐藏观察面板
B 显示/隐藏沙盒面板
F11 循环 窗口 / 全屏 / 无边框全屏（保留任务栏）
V 地图全屏 / 900x506 等比缩小（也可拖右下角手柄自由缩放）
L 显示/隐藏飞船等级
Tab 切换视野显示模式（6 档，含关闭）
O 关闭/开启叛乱系统
C 关闭/开启友军碰撞（默认开）
F 关闭/开启友军伤害（默认开；控制激光和碰撞是否伤友军）
空格 暂停/继续
1 / 2 / 3 / 4 速度 0.5x / 1x / 2x / 4x
F2 选中一艘飞船（调试/查看属性）
F3 性能叠加层（FPS、模拟耗时、实体数、种子、停滞、友军碰撞、地图缩放）
F5 打乱所有舰队位置，立即进入混战（压力测试/演示）
左键点击飞船可以查看其具体信息，点击空处可以关闭；点面板/排行窗口不会误选。
右键 取消创造面板的手动放置预览
R 还原沙盘

创造面板：
- N 打开；可拖动，也可点“弹出”变成独立桌面窗口，主窗口只留地图。
- 创造物：飞船 / 小行星 / 机遇。
- 出现方式：投放 / 增援 / 传送门；机遇不支持增援。
- 飞船：阵营、数量 1-2000、方阵/圆阵/密集/随机、初速（默认 40）、
  属性加点（生存/攻击/机动/生产/视野）；等级 = 1 + 总加点，直接输入等级会随机分配（上限 200 点）。
- 小行星：小行星/彗星、半径 4-600、数量 1-360、初速（默认 30 / 320）、不规则度 0-100%。
- 机遇：持续 1-3600 秒、最大范围 10-800、种类（增援/生存/进攻/机动/生产/领域）。
- 随机创造：地图随机位置/方向。
- 手动放置：点“手动放置”后面板自动收起；鼠标显示范围虚线圈，第一次点击定范围/位置，
  飞船/小行星第二次点击定初速方向；机遇/传送门一次点击完成；右键/Esc 取消。
  预览线条跟随创造物：飞船用阵营色、小行星灰色、机遇用类型色；增援会显示反向界外出发点。
- 传送门：默认 1000 血（可改到 1,000,000），固定、无碰撞箱、旋转旋涡；
  每 1/3/5/10 分钟原地刷一波。飞船身份视为该阵营飞船（会被敌舰攻击），
  小行星身份为灰色，机遇身份为类型色。

观察面板：
- K 打开；四个开关：视野显示、等级显示、传送门信息、称号显示；底部有全开/全关。
- 传送门信息默认开：关闭后只保留旋涡和血环，不显示名称/血量/倒计时。
- 称号显示默认开：击杀数达到 5 获得称号的飞船，会在飞船下方实时显示金色称号。
- 视野显示关闭时会记住上次模式，重新打开恢复；Tab 仍可切换模式。

沙盒面板：
- B 打开；战场大小按面积倍率：0.25x=800x450、1x=1600x900、4x=3200x1800（长宽各 2 倍）、
  9x=4800x2700（长宽各 3 倍）。
- 改变战场会按比例重排现有对象并重建网格，镜头始终缩放到整张地图；窗口大小不变。
- “按当前战场重开”用当前种子/初始船数在新战场重开。
- 显示模式：窗口 / 全屏 / 无边框全屏（留任务栏）；F11 循环。
  全屏覆盖整个显示器（任务栏被盖住）；无边框全屏按工作区铺满、任务栏可见。
  内部按 1600x900 等比缩放，非 16:9 屏幕留黑边。

统计面板：
- 打开后是游戏内独立浮窗，可拖动标题栏移动，右上角 X 关闭。
- 范围：阵营排行 / 个体排行。
- 时间：累计 / 近1分钟 / 近5分钟 / 近10分钟 / 仅峰值。
- 显示淘汰者：独立开关；打开后把已灭亡阵营/个体一起加入当前排行，关闭只看存活对象。
- 个体筛选：全部/红/蓝/绿/黄、最低等级（- / +，Shift 步进5）、仅称号。
- 指标：阵营 25 项、个体 14 项；点选指标后按“打开排行窗口”。
- 排行窗口：实时伸缩/换位；顶部小按钮可调行数（3-14）、行宽（260-700）、格式1/2。
  格式2 把文字和细方条分开；每行右侧数字单独占列，不会被统计条遮住。
- 可拖动、单独关闭、数量无上限；“关闭全部子窗口”一键清空。
- 个体排行显示飞船图案、#编号、等级、称号；阵营显示颜色、名称、#阵营编号。
- 仅峰值：当前项取历史最高瞬时值；累计项取历史最佳 1 分钟；窗口底部显示全服纪录。
- 阵营被清空后重生会换新名字并分配新编号；打开“显示淘汰者”可看到多个同色不同名阵营。
- 弹出：把排行窗口变成独立桌面窗口，可拖到游戏窗口外/副屏；收回回到游戏内。
- 累计项都支持最近 1/5/10 分钟；统计快照 10 Hz 刷新，条宽/数值做插值。

游戏规则：
飞船-作战单位，会通过游戏开始、飞船制造产生。
当一艘飞船击杀数达到3后，会获得粒子拖尾，拖尾会随着杀敌数增加而变长；击杀数达到5后，会获得称号（默认在飞船下方实时显示，可在观察面板关闭）。
飞船在自己阵营资源达到10点后开始建造，建造10秒后复制一艘同级飞船；增援区域每3秒复制一艘区域内的飞船。

阵营-四种颜色的阵营，飞船会产生叛乱改变阵营。
某个阵营被清空后，叛乱系统有概率把其他阵营的飞船拉过来。

圆形区域-各种机遇，会随机出现。
白色：增援
红色：生存升级
绿色：机动升级
黄色：进攻升级
紫色：领域升级
蓝色：建造升级

天体-小行星 可通过开采获得资源。
特殊天体：急速小行星（彗星），体型大，速度极快；撞到飞船会按相对速度造成重创。
激光-会被路径上的敌对飞船、小行星、光点拦截；打在光点上一发打坏。
光点-有血量；对石头碰撞有较高抗性，被彗星反复碾过仍会碎。
开局会先放 6 颗场内小行星，之后每 6~16 秒生成一波；小行星碎裂时产生光点。

性能提示：
- 默认最多 20000 艘；命令行 --ships N 是每阵营数量（例如 --ships 2500 = 10000 艘）。
- 万艘规模下，视野圈/光晕/4x MSAA 会自动关闭；观察面板或 Tab / L 仍可手动打开。
- 友军碰撞/友军伤害默认开；按 C / F 切换，或在命令行加 --no-friendly-collision / --no-friendly-fire。
- F3 可看当前 FPS 与每步模拟耗时；F5 是最直接的混战压力测试。
- 创造面板一次最多 2000 艘飞船 / 360 颗小行星 / 8 个传送门；2000 艘时仍约 60 FPS。
- 统计面板/排行窗口开 1~3 个对 4k 规模基本无感；开很多窗口会多扫几遍统计，建议按需关闭。
- 地图缩放（V / 右下角手柄）只缩小显示，不改变世界尺寸；缩得很小时文字也会变小。
- 无窗口基准：Darkfield Lightwar.exe --bench 10000 --bench-seconds 8 [--no-friendly-collision --no-friendly-fire]
