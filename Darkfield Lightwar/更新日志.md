## v2.1.0 — 2026-10-28（统计面板 / 统计排行 / 名称池扩充）

### 新增

- **统计面板**：按 `M` 或 `H` 开关；`Esc` 关闭面板。面板是游戏内的独立浮窗，可拖动。
  - 范围：阵营 / 个体。
  - 时间：累计 / 近 1 分钟 / 近 5 分钟 / 近 10 分钟 / **仅峰值**。
  - **显示淘汰者**：独立开关，把已灭亡阵营/个体一起加入当前排行；关掉就只看存活对象。
  - 个体筛选：阵营（全部/红/蓝/绿/黄）、最低等级（点 `-` / `+`，按住 Shift 步进 5）、仅称号。
  - 指标：阵营 25 项、个体 14 项；点击指标后按“打开排行窗口”生成独立排行窗口。
- **排行窗口**：
  - 从上到下横向数据条，实时变化、平滑换位/伸缩。
  - **小按钮**：`行数 -/+`（3–14 行）、`行宽 -/+`（260–700，方条区域宽度）、`格式1/2`
    （格式 2 把文字和细方条分开，方条更细）。
  - **右侧数值列独立**：数值不再盖在统计条上，条长再满也不会遮住数字。
  - 每窗可拖动，单独 `X` 关闭；窗口数量无上限；面板底部“关闭全部子窗口”一键清空。
  - **`弹出` / `收回`**：排行窗口可以弹出成独立操作系统窗口，拖到游戏窗口外/副屏；
    弹出窗有独立字体/渲染器（GL 纹理不能跨窗口共享），收回后回到游戏内原位置。
  - 个体排行显示飞船图案、`#编号`、等级、称号；阵营排行显示阵营颜色、名称和 `#阵营编号`。
  - 面板和游戏内子窗口都盖在 HUD 上；点击窗口不会误选飞船。
- **统计项**（阵营）：
  - 飞船数、累计击杀、累计输出、累计开采、资源、累计收集资源、平均等级、战力（等级和）、
    累计友伤、累计友伤次数、累计损失、累计建造、累计承伤、累计受伤次数、总生命、平均生命、
    总装甲、平均装甲、平均击杀、最高等级、输出/承伤比、击杀/损失比、人均输出、人均开采、人均收集。
- **统计项**（个体）：
  - 等级、累计击杀、累计输出、累计收集、累计开采、累计造成友伤次数、累计友伤、累计承伤、
    累计受伤次数、生命、装甲、存活时间、击杀/等级、每分钟输出。
- **仅峰值**：当前存活阵营/个体参与。
  - 当前项（飞船数/战力/资源/等级/生命等）取历史最高瞬时值；
  - 累计项（击杀/输出/开采/收集/友伤/承伤等）取历史最佳 1 分钟；
  - 排行窗口显示“全服纪录”。
- **淘汰者开关**：
  - 阵营：飞船数归 0 时归档为“淘汰阵营”，保留名字、阵营编号、颜色和峰值/最近窗口。
  - **阵营重生**：空槽位重新出现飞船时，换一个新名字并分配新的 `#编号`，累计值从 0 开始；
    因此历史里会出现多个同色、不同名字、不同编号的阵营。
  - 个体：死亡瞬间归档最终统计、称号、阵营编号和最近 1/5/10 分钟窗口。
  - 开关打开后，当前排行会把淘汰对象一起排序；关掉只显示存活对象；阵营和个体都适用。

### 实现 / 性能

- 新增 `include/Stats.h`、`src/Stats.cpp`：指标枚举、中文名、格式化、快照结构。
- `World` 在伤害/击杀/收集/采矿/建造事件处做 **O(1)** 累加；约 10 Hz 扫描一次当前聚合
  （飞船数、等级和、生命/装甲和、最高等级），供所有窗口共享。
- 最近 1/5/10 分钟用 **10 秒桶 × 60 的环形缓冲** + 当前桶实时增量；每船约 2 KB、
  每阵营约 2.5 KB，内存固定，不会随运行时间增长。
- 个体排行按 `(指标, 时间范围, 筛选条件, 是否含淘汰者)` 缓存，统计版本每 0.1 秒更新一次；
  多个窗口共享同一份快照，不会每个窗口每帧全量扫船。
- **阵营轮回**：`refreshStats()` 里检测每个颜色槽位的飞船数；0 → 归档旧阵营（名字/编号/峰值/
  最近窗口），>0 且之前为 0 → `assignFactionIdentity()` 换名、分配新编号、清空累计/峰值/资源。
  历史淘汰阵营存在 `StatsSnapshot::eliminatedFactions`，UI 用颜色槽位 + `#编号` 区分。
- **个体淘汰档案**：`DeadShipRecord` 保存最终累计、称号、等级、存活时间、最大生命/装甲、
  死亡瞬间的最近 1/5/10 分钟窗口；`topIndividuals(..., includeEliminated)` 合并存活/淘汰个体。
- **弹出桌面**：每个弹出窗创建独立 `sf::RenderWindow` + 独立 `Renderer`（只加载字体，不建图集），
  避免 SFML 纹理跨 GL 上下文；主循环 `pollDetachedWindows()` 处理关闭/收回/行数/行宽/格式，
  `drawDetachedWindows()` 每帧单独绘制；原生标题栏负责拖出游戏窗口。
- 性能：10,000 艘、0 颗注入、3 秒短基准多次 3 次中位 **6.3–7.2 ms/步**（v2.0.4 全关 5.99 ms/步，
  统计开销约 5–10%，在短测噪声内）；20,000 艘 3 秒 **18.7–19.2 ms/步**；
  10,000 艘 12 秒（跨过 10 秒桶边界）**6.40 ms/步**。
- GUI 4,000 艘启动 + 面板 + 3 个排行窗口 60 FPS（F3 截图时 1,591 艘存活、模拟 1.9 ms/步）；
  10,000 艘启动、开面板、开排行窗口无崩溃。

### 已知取舍

- 统计快照 10 Hz 刷新；条宽/数值在两次刷新之间做插值，所以看起来是连续跳动，但数据本身是 10 Hz。
- “仅峰值”的累计项是 **历史最佳 1 分钟**，不是单调累计总量（累计总量看“累计”）。
- “显示淘汰者”在最近 1/5/10 分钟里显示的是对象**淘汰时**的最近窗口，不是淘汰后继续衰减；面板注明了“按淘汰时数据”。
- 个体最近 1/5/10 分钟以 10 秒桶近似，边界最多有 10 秒粒度；不会随时间增长内存。
- 淘汰个体会保留一条死亡档案（含称号/最近窗口）；长时间连续运行、死亡数很大时会占内存，
  目前不做上限截断，重开/重置会清空。
- 排行窗口默认是游戏内 SFML 浮窗；点“弹出”会创建独立 OS 窗口和独立字体/GL 上下文，
  每个弹出窗约多一份字体纹理（不建小行星图集）；收回后释放。

## v2.0.3 — 2026-10-28（彗星伤害 / 激光拦截 / 友军碰撞开关）

### 修复

- **小行星/彗星对飞船没伤害**：`updateCollisions()` 的飞船-小行星分支用 `s.vel.dot(normal)` 计算撞击速度。飞船静止、彗星迎面撞来时 `vn=0`，于是只做位置推开、不扣血；彗星 300–430 px/s 穿过去也毫发无损。
  - 改为相对速度 `relVel = s.vel - a.vel`，`impact = max(0, -relVel.dot(normal))`。
  - 伤害：普通小行星 `2 + impact*0.4`，彗星 `2 + impact*0.35`（彗星一记重创，通常不秒杀满血船）；冲量也按相对速度反弹。
  - 自测：静止船被 500 px/s 彗星正面撞，hp 100→0；普通船被擦撞会掉血。

### 优化

- **激光会被路径上的物体拦截**：
  - `Grid::queryRay()`：DDA 沿射线走网格，只查射线经过的格子。
  - `resolveBeam()`：沿激光路径找最近的敌对飞船 / 小行星 / 光点，命中点作为光束终点；先挡住的先受伤，后面的目标不受伤害。
  - 敌对小行星/飞船/光点都会拦截；**友军不挡激光**，避免默认出现友军误伤。
  - 自测：光点挡激光（光点碎、目标满血）、小行星挡激光（小行星掉血、目标满血）、敌对飞船挡激光（挡板掉 10 血、目标满血）。
- **光点血量**：
  - `LightPoint` 新增 `health/maxHealth/hitCooldown`；初始 10 血，初始激光 10 伤害一发打坏。
  - 小行星/彗星也能砸坏光点：碰撞伤害按相对速度 `impact*0.02`，比激光抗性高；被彗星反复碾过仍会碎。
  - 受损光点在渲染上会变暗。
  - 自测：激光一发打碎光点；彗星碾过光点使其 `active=0`。

### 新增

- **友军碰撞开关**：
  - 游戏内按 `C` 切换，底部状态栏/F3 调试层显示“友军碰撞 开/关”；默认关（万艘性能取舍）。
  - 开启后同阵营飞船做位置分离 + 弹性冲量，**只推挤、不扣血**；每对只处理一次（`j > i`）。
  - 命令行 `--friendly-collision` 可让 GUI/`--bench` 开局即开启，便于性能测试。
  - 自测：默认重叠距离 5.0；开启 9 步后 10.0。
  - 10k、0 颗注入小行星短基准：默认 6.89 ms/步，开友军碰撞 6.62 ms/步（同机噪声内）。

### 未做 / 风险

- **像素级小行星碰撞箱**仍是想法，没有在本版实现。现在的碰撞/激光仍用圆形宽相；真正的像素窄相需要逐像素求交和穿透法线，360 颗天体 × 万艘的 20 Hz 碰撞会明显吃性能，建议单独做并配基准。
- 激光拦截只跳过了同阵营飞船；如果你希望友军也挡激光/误伤，这需要再加一个独立开关。

## v2.0.2 — 2026-10-28（后期停滞 + 采集横向惯性）

### 修复

- **后期飞船原地不动（等级 40/41 也不走）**：
  - 根因：`copyAttributes()` 对 `preferredSpeed` 做无夹取的 `±5` 随机游走；建造船 `drivingSkill=0`，`mixed` 基本就是 `preferredSpeed`。一旦游走到 `<=0`，`targetSpeed<=0`，`updateSpeedControl()` 的 `diff > 0` 永远不成立，船永久停住；停在区域里还会继续升级，于是出现等级 40+ 的“钉子户”。
  - 修复：`preferredSpeed` 复制时夹到 `15–30`；所有非采集状态的 `targetSpeed` 兜底下限 `12`；采集状态改走独立速度控制。
  - F3 调试层新增 `停滞` 计数（连续 >3 秒速度 <1 px/s 的活跃船数），可以直接看有没有停住的船；bench 末尾也会输出 `final_stopped`。
- **采集光点仍会绕圈（横向惯性）**：
  - 根因：旧控制器只沿船头方向推/刹，横向速度不受控；船头转向需要时间，横向惯性让船围绕光点画圈。v2.0.1 的“横向脱靶量”只是不推，并没有主动抵消侧滑。
  - 修复：`Collecting` 改为完整速度匹配——期望速度指向光点，速度误差（含横向分量）转成加速度（RCS 侧推）；横向速度越大，前进目标速度越低，>28 px/s 时先刹掉侧滑；`updateShips()` 的 Collecting 分支只负责转头。
  - 自测：初始横向 40 px/s、距离 40px，3.22 秒收集；收集瞬间相对光点方向的横向分量 −3.0 px/s。

### 验证

- `tmp/selftest.cpp` 全部 PASS：
  - `stuck_preferred: speed=11.3 childPref=15.0`（负 `preferredSpeed` 不再静止，子船复制被夹住）
  - `collect_lateral: collected=1 steps=193 (3.22s) vy_1s=16.1 lateral_end=-3.0`
  - 原有 `edge_light` / `collect_converge` / `flee` / `asteroid_lifecycle` 继续 PASS
- Release x64 / Debug x64 0 error。

## v2.0.1 — 2026-10-28（接手修复）

这一版只修上一版暴露出来的四个体验问题，不改架构和玩法基准。

### 修复

- **小行星数量卡在 360、屏幕上却没有小行星**：旧版在窗口外 1000px 的「奇点」周围生成，速度只有 3–10 px/s，而且飞出窗口后不回收。360 个槽位被屏幕外的天体占满后，新波次再也生成不出来。

- **边缘光点捡不到、飞船绕光点转圈**：

  - 逃跑期间用侧向/后向推进器沿远离威胁的方向加速（不等掉头完成），同时以 1.35× 转向速率掉头。

## v2.0.0 — 2026-10-28（底层重构）

这是把「修修补补的单文件 + 拆到一半的 src」推倒重写的一版。玩法基准是 `versions/ver0.1.4.cpp`，但模拟、AI、碰撞、渲染、UI 全部换成了新架构。

### 性能

- 4,000 艘混战：**60 FPS**（模拟 2.5–2.6 ms/步）。
- 10,000 艘混战：**59.7 FPS**（9,966 艘存活，6.6 ms/步）；首次接触 60.5 FPS / 11.9 ms。
- 无窗口基准：4k 392 步/秒、8k 179、10k 133、20k 51 步/秒。
- 小行星渲染：360 颗独立纹理 2.90 ms → 图集 1.59 ms。

### 架构

- 数据导向实体池：`Ship/Asteroid/LightPoint` 连续数组 + 空闲槽 + generation 句柄；热路径不再用 `shared_ptr`，不再用字符串 `getType()`。
- 三层网格：100px AI/目标、24px × 4 阵营碰撞、光点收集。
- AI：目标保留 + 32/80/视野环形最近邻；决策 0.45–0.9 s；障碍扫描 5 Hz。
- 碰撞：只检测异阵营，20 Hz（每 3 个固定步），平方距离早退。
- 固定 60 Hz 步长 + 累加器，模拟与帧率解耦；0.5×/1×/2×/4× 速度、暂停。
- 渲染：飞船 2 次批量 draw；小行星 2048×2048 图集 1 次 draw；光点/激光/拖尾各 1 次；等级数字预生成图集。
- 大舰队自适应：>120 艘只画选中视野圈；>1500 艘关光晕；>500 艘/阵营关 4×MSAA。
- 双显卡笔记本导出 `NvOptimusEnablement` / `AmdPowerXpressRequestHighPerformance` 请求独显。

### 修复 / 改进

- 删除 14 个无法链接的旧 `.cpp` 和 14 个旧 `.h`；工程只剩 5 个 .cpp / 4 个 .h。
- 修复 `Globals.cpp` / `main.cpp` 重复定义全局变量。
- 修复 `Asteroid` / `PhysicsSystem` / `Spaceship` 缺失实现导致的链接失败。
- 恢复中文 UI 字体回退（旧拆分层只加载 Arial，中文会空白）。
- 修复窗口被创建两次：启动瞬间会枚举到已销毁的 HWND，截图工具会抓错窗口。
- 修复说明书 `P` / 代码 `O` 键位不一致；补充 `Tab/F2/F3/F5/空格/1-4/R`。
- 修复旧版 UI 底部阵营面板与状态栏重叠、历史开关背景与文字错位。
- 开局放 6 颗场内小行星，避免前 16 秒空场；第一波提前到约 4 秒。
- 新增无窗口基准：`--bench / --bench-seconds / --bench-asteroids / --ships`。
- 新增 F2 选中、F3 性能层、F5 立即混战、暂停/倍速。

### 分发

- 新增 `package.ps1`：构建 + 打包 `dist\Darkfield Lightwar v2.0.0 win64\` 与 zip（约 8.4 MB）。
- 随包带 app-local MSVC 运行库、SFML 3 个 DLL、中文字体、`names/`；不依赖系统 VC++。
- 已在带空格/中文的路径实际启动并验证（`docs/portable-chinese-path.png`），zip 解压后再跑基准也通过。

### 有意的取舍

- 同阵营飞船不互相碰撞；异阵营仍碰撞、扣血。万艘舰队里自己人叠在一起是常态，保留同阵营分离会吃掉约一半碰撞预算。
- 碰撞 20 Hz：高速下最多重叠 3 帧；最高 120 px/s，3 帧约 6 px < 船半径 10，不会穿透。
- 大舰队自动关视野圈/光晕/MSAA；按 Tab/L 仍可手动打开。
- 20,000 艘是压力上限（约 51 步/秒），不是 60 FPS 目标；再往上需要多线程 AI/碰撞或更大战场。

### 保留

- `versions/` 历史单体版本；`backup/before-refactor-*.zip` 重构前完整源码备份。
- 玩法：四阵营、叛乱、建造、增援/五种升级区域、小行星采矿、光点、击杀拖尾/称号、历史战绩、视野模式 6 档。
