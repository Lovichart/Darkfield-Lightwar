# 暗域光战 v2.2.0

一个四人阵营的太空沙盘：舰队自动交战、采矿、建造、抢升级区域，飞船会叛乱换阵营。

## 开始

双击 `Darkfield Lightwar.exe` 即可。  
**请复制整个文件夹**，不要只拷 exe；`fonts/` 和 `names/` 是运行时资源。  
从任何目录启动都可以，程序会按 exe 所在目录找资源。

建议 Windows 10/11 64 位；需要支持 OpenGL 2.1 的显卡。笔记本双显卡会自动请求独显。

## 统计面板 / 统计排行

按 `M` 或 `H` 打开。面板里先选“阵营 / 个体”，再选指标和时间范围，点“打开排行窗口”。

- **阵营排行**：按所选指标从高到低排；阵营名后带 `#编号`，被清空重生后编号会变。
- **个体排行**：显示飞船图案、`#编号`、等级和称号；可筛阵营、最低等级、仅称号。
- **时间范围**：
  - 累计：本局开始至今；
  - 近 1 / 5 / 10 分钟：对应时间窗内的增量；
  - 仅峰值：当前项取历史最高瞬时值，累计项取历史最佳 1 分钟（窗口底部会显示全服纪录）。
- **显示淘汰者**：独立开关。打开后把已被清空的阵营、已死亡的个体一起加入当前排行；
  关掉就只看存活对象。淘汰阵营会保留旧名字/编号；所以打开后能看到同色但不同名字、不同编号的多个阵营。
- **排行窗口**：
  - 顶部小按钮：`行数 -/+`（3–14 行）、`行宽 -/+`（方条区域宽度）、`格式1/2`
    （格式 2 把文字和细方条分开，方条更细）。
  - 每行右侧的数字单独占一列，不会被统计条遮住。
  - 实时伸缩、换位；可拖动标题栏移动、点右上角 `X` 关闭。
  - `弹出` 会把窗口变成独立的桌面窗口，可以拖到游戏窗口外或副屏；`收回` 回到游戏内。
- **窗口数量无上限**；面板底部“关闭全部子窗口”一键清空。
- 指标包括：飞船数、击杀、输出、开采、资源、收集、平均等级、战力、友伤、友伤次数、损失、建造、
  承伤、受伤次数、生命、装甲、平均击杀、最高等级、各种比率，以及个体的等级/击杀/输出/收集/开采/
  友伤/承伤/受伤/生命/装甲/存活时间/击杀效率/每分钟输出等。

## 创造面板（N）

按 `N` 打开。面板可拖动，也可以点“弹出”变成独立桌面窗口，主窗口只留地图。

- **创造物**：
  - **飞船**：阵营颜色、数量 1–2000、方阵/圆阵/密集/随机、初始速度（默认 40）。
    属性加点支持直接输入；等级 = 1 + 总加点，输入等级回车会自动随机分配属性（上限 200 点）。
  - **小行星**：小行星/彗星、半径 4–600（可以非常大）、数量 1–360、初速（默认 30 / 320）、不规则程度。
  - **机遇**：持续时间、最大范围、种类（增援/生存/进攻/机动/生产/领域）。
- **出现方式**：投放（直接出现）/ 增援（从界面外飞进来）/ 传送门。
  机遇不支持增援。
- **随机创造**：地图随机位置。
- **手动放置**：点“手动放置”后面板自动收起；鼠标处显示范围虚线圈。第一次点击确定范围/位置；
  飞船/小行星再点一次确定速度方向，机遇/传送门一次点击完成。右键或 `Esc` 取消。
  预览线条颜色跟随创造物：飞船用阵营色，小行星灰色，机遇用类型色。
- **传送门**：默认 1000 血（可输入到 1,000,000），固定、无碰撞箱、旋转旋涡；
  每 1/3/5/10 分钟原地刷一波。飞船身份视为该阵营飞船（会被敌舰攻击），小行星身份为灰色，机遇身份为类型色。
  落成时立即刷第一波。

## 观察面板（K）

四个开关 + 全开 / 全关：

- **视野显示**：等价于 Tab；关闭时记住上次模式，重新打开恢复。
- **等级显示**：等价于 L。
- **传送门信息**：传送门上方的名称 / 血量 / 下一波倒计时（默认开；关闭后旋涡和血环还在）。
- **称号显示**：默认开。击杀数达到 5 的飞船，称号会实时显示在飞船下方（金色，带黑影/黑底）。

## 地图缩放（V）

- `V` 在全屏和 900×506（16:9）之间切换；拖右下角手柄可自由等比缩放。
- 缩小后仍能看到整张地图，所有物体等比缩小；面板/文字 UI 保持原尺寸。
- 缩放状态下选船、手动投放的坐标会自动换算。

## 沙盒面板（B）

- **战场大小（面积倍率）**：
  - `0.25×` = 800×450；`1×` = 1600×900（原版）；`4×` = 3200×1800（长宽各 2 倍）；
    `9×` = 4800×2700（长宽各 3 倍）。
  - 改变战场会按比例重排现有对象并重建网格，镜头自动缩放到整张地图；窗口大小不变，
    所以 4×/9× 时物体等比变小，0.25× 时变大。
  - “按当前战场重开”用当前种子/初始船数在新战场重开。
- **显示模式**：窗口 / 全屏 / 无边框全屏（留任务栏）；`F11` 循环。
  - 全屏：覆盖整个显示器，任务栏被盖住。
  - 无边框全屏：按工作区铺满，任务栏可见。
  - 内部按 1600×900 等比缩放，非 16:9 屏幕留黑边，不会变形。

## 想打大规模

默认每阵营 5 艘（共 20 艘）。命令行可以加参数：

```text
Darkfield Lightwar.exe --ships 1000      # 每阵营 1000，共 4000 艘
Darkfield Lightwar.exe --ships 2500      # 每阵营 2500，共 10000 艘
Darkfield Lightwar.exe --unlimited       # 不锁 60 帧
```

进入游戏后按 **F5** 让四个阵营立刻混战，再按 **F3** 看帧率。  
10,000 艘在测试机上约 57–59 FPS；20,000 艘是压力上限（约 50 模拟步/秒）。
统计面板的统计快照 10 Hz 刷新，开 1–3 个排行窗口对 4,000 艘规模基本无感。
创造面板一次 2,000 艘仍约 60 FPS。

## 性能设置

- 大舰队会自动关闭视野圈、飞船光晕和 4×MSAA，保证帧率。
- 想看视野圈：按 Tab；想显示等级：按 L。
- 如果觉得画面糊/卡：优先确认是否在用独显；F3 里看 FPS 与模拟耗时。
- 统计面板/排行窗口默认是游戏内浮窗；开很多窗口时会多扫几遍统计，建议同时保留 1–3 个。
- `弹出` 的独立窗口会多一份字体/GL 上下文，收回后释放；不要一次弹出几十个。

## 故障排查

- **闪退/缺 DLL**：确认上面几个 DLL 与 exe 在同一目录；安装 Microsoft Visual C++ 2015–2022 x64 运行库也可以。
- **中文变方块/空白**：确认 `fonts/LXGWWenKaiTC-Light.ttf` 存在；程序也会回退到系统微软雅黑。
- **窗口黑屏/极小**：更新显卡驱动；确认没有把 `fonts/names` 拷丢。
- **太卡**：把 `--ships` 降到 500–1000；按 F3 看是模拟耗时高还是帧率被锁；先关掉不用的排行窗口。
- 控制台默认隐藏；无窗口基准请用 `--bench`（见 `交接文档`）。
